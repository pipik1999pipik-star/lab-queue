# Очередь на лабы: Telegram Mini App

Общая очередь на несколько лабораторных. В каждой по 30 мест (можно от 1 до 100), записаться можно сразу на несколько лаб, выбрать конкретное место, выйти. Админ отмечает «сдал(а)», убирает людей, создаёт и настраивает лабы. Список обновляется у всех каждые 5 секунд.

Нужен только Node.js 18+. Зависимостей нет.

## 1. Проверить на компьютере

```bash
node server.js
```

Откройте http://localhost:3000. Без `BOT_TOKEN` сервер работает в режиме проверки: подпись Telegram не проверяется, вы один пользователь и админ.

Если просто открыть `index.html` файлом, без сервера, включится демо-режим с данными только на вашем устройстве.

## 2. Выложить в интернет (нужен HTTPS)

Telegram открывает мини-приложения только по https. Подойдёт любой хостинг, где запускается Node: Render, Railway, Fly.io, свой VPS.

- Команда запуска: `node server.js`
- Переменные окружения:
  - `BOT_TOKEN` токен бота от @BotFather (обязательно, иначе любой сможет записаться от чужого имени)
  - `ADMIN_IDS` Telegram ID админов через запятую, например `123456789,987654321`. Свой ID можно узнать у @userinfobot. Если не задать, админом станет первый, кто откроет приложение.
  - `CAPACITY` мест в новых лабах по умолчанию (30)
  - `LABS` сколько лаб создать при первом запуске (4)
  - `DB_FILE` путь к файлу с данными (`data.json` рядом с сервером)

Важно: на бесплатных хостингах диск часто стирается при перезапуске. Подключите постоянный диск (volume) и укажите `DB_FILE` на него, иначе очередь обнулится.

Для быстрого теста с телефона без хостинга: `npx cloudflared tunnel --url http://localhost:3000` выдаст временный https-адрес.

## 3. Подключить к боту

1. В @BotFather создайте бота командой `/newbot` (или возьмите существующего).
2. `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button**, вставьте https-адрес сайта и название кнопки, например «Очередь».
3. Отправьте боту ссылку на него в чат группы. Студенты открывают бота и нажимают кнопку меню.

Можно сделать и отдельное приложение: `/newapp` в @BotFather, тогда получите ссылку вида `t.me/ваш_бот/queue`.

## Как это работает

- Клиент: `index.html`, одна страница без сборки.
- Сервер: `server.js` проверяет подпись `initData` по токену бота, так что имя в очереди подделать нельзя. Данные лежат в `data.json`.
